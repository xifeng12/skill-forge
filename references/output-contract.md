# Output Contract

What skill-forge produces unless the user asks otherwise.

## Deliverables

1. A working skill directory
2. A trigger-aware `SKILL.md`
3. Aligned `agents/interface.yaml`
4. Optional `references/`, `scripts/`, `evals/`, `reports/`, `manifest.json`
5. A short summary of boundary, exclusions, gates, and next steps

## Principles

- Start minimal — add structure only when evals show it's needed
- Every file should have a clear reason to exist (no "just in case" scaffolding)
- The `description` field in SKILL.md is the most important deliverable — it determines whether the skill ever loads
